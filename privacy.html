MathSnap 개인정보 처리방침

최종 수정: 2026-10-20

MathSnap(이하 "앱")은 사용자의 개인정보를 수집, 저장, 판매하거나 제3자에게 제공하지 않습니다. 이 문서는 앱이 어떤 데이터를 어디서 처리하는지 설명합니다.

1. 수식 인식은 전부 기기 안에서 이루어집니다

  • 수식 인식(OCR)은 앱에 내장된 기계학습 모델이 사용자의 Mac에서 직접 수행합니다.
  • 사용자가 드롭하거나 붙여넣은 이미지와 인식 결과(LaTeX)는 어떤 서버로도 전송되지 않습니다.
  • 계정 생성이나 로그인이 필요하지 않습니다.

2. 기기에만 저장되는 데이터

  • 변환 이력(원본 이미지와 LaTeX, 최대 100개)은 사용자 Mac의 앱 샌드박스 컨테이너 안에만 저장됩니다.
  • 이력은 앱 안에서 언제든 개별 또는 전체 삭제할 수 있으며, 앱을 삭제하면 함께 제거됩니다.
  • 복사 횟수와 "광고 제거" 구매 여부는 앱 설정으로 기기에 저장됩니다. 이 값은 기기를 벗어나지 않습니다.

3. 네트워크 통신

앱은 아래 두 경우에만 인터넷에 접속합니다.

3.1 안내 배너

  • 앱은 개발자가 운영하는 정적 파일 한 개(JSON)를 내려받아 팝오버 하단에 안내 배너를 표시합니다.
  • 이 요청에는 사용자 식별자, 기기 식별자, 사용 기록 등 어떤 개인정보도 포함되지 않습니다. 광고 네트워크나 추적 SDK는 사용하지 않습니다.
  • 파일을 호스팅하는 서비스(GitHub Pages)는 일반적인 웹 서버와 마찬가지로 접속 IP 주소를 서버 로그에 일시적으로 기록할 수 있습니다. 개발자는 이 로그를 수집하거나 분석하지 않습니다.
  • "광고 제거"를 구매하면 배너가 표시되지 않습니다.

3.2 앱 내 구입

  • "광고 제거"와 후원(팁) 결제는 Apple의 App Store 결제 시스템(StoreKit)으로 처리됩니다.
  • 결제 정보는 Apple이 처리하며, 앱은 카드 번호 등 결제 수단 정보에 접근하지 않습니다. 앱이 받는 것은 구매가 완료되었다는 사실뿐입니다.
  • Apple의 개인정보 처리에 대해서는 Apple의 개인정보 처리방침을 참고하세요.

4. 사용하지 않는 것

  • 분석(애널리틱스) 도구
  • 광고 SDK, 추적 식별자(IDFA 등)
  • 크래시 리포팅 서비스
  • 쿠키, 계정, 서버 측 사용자 데이터베이스

5. 아동의 개인정보

앱은 연령에 관계없이 개인정보를 수집하지 않으므로, 아동으로부터도 어떠한 정보도 수집하지 않습니다.

6. 변경

이 방침이 바뀌면 이 페이지에 갱신 날짜와 함께 반영합니다. 네트워크 통신이나 데이터 처리 방식이 바뀌는 경우 앱 업데이트 설명에도 명시합니다.
